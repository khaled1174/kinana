# Kinana 0.4.0 beta RC1

## Highlights

Kinana 0.4 makes it easier to review skills before adding them to a vault and safer to activate high-risk skills in a project. This release candidate is for Apple Silicon Macs running macOS 27.0 or later.

## What's new

- **Review high-risk activations in Kinana.** The app shows the audit findings and asks for explicit confirmation. The CLI and router direct you to the app for that approval.
- **Keep secret values out of audit excerpts.** Findings retain the file, line, and reason. Refresh an older audit to see excerpts generated by the current rules.
- **Review imports together.** Edit a skill's description before adding it, select eligible skills from a folder, and choose a version when two skills conflict. The original files stay intact.
- **Choose a classifier for the current import.** Preview the estimate, change the agent for the batch, or skip classification. Skill details remember the latest reason a classification was skipped.
- **Review before you undo.** Kinana shows how many descriptions will return to review before undoing automatic approval. Project cards also make it clearer when no skills have been activated through Kinana.
- **Use reviewed Pi releases.** Kinana supports Pi 1.5.2 and 1.6.1. The model picker uses the defaults of the installed, verified release. If the installed version is awaiting review, you can choose Claude for the current batch.

## Install

Open `Kinana-0.4.0-beta-rc1-arm64.dmg` and drag **Kinana.app** to **Applications**. Launch it from there. On first launch, macOS may ask you to confirm opening an app downloaded from the internet.

## Verify

Keep the disk image, `SHA256.txt`, and `THIRD_PARTY_NOTICES.md` in the same folder. Run `shasum -a 256 -c SHA256.txt` to check the disk image and notices. The app and disk image are Developer ID signed and notarized.

## Known issues

- Pi classification is experimental and off by default. The local model list may show a model that your provider does not offer to your account.
- Some ordinary reads may be flagged when variable names resemble credentials. Check the audit reason before approving an activation.
- Codex can be used for activation and routing. Direct Codex classification remains unavailable.
