# تثبيت Kinana 0.3.0-beta على macOS

الحزمة الموقّعة لأجهزة Apple Silicon. أدنى إصدار macOS في الحزمة 27.0، وجرى التحقق من الحزمة على macOS 27.2.1.

1. نزّل صورة التثبيت Kinana-0.3.0-beta-arm64.dmg وملف SHA256.txt من صفحة الإصدار نفسها.
2. في مجلد التنزيل، شغّل الأمر التالي. يجب أن يظهر OK للصورة.

   ~~~sh
   shasum -a 256 -c SHA256.txt
   ~~~

3. افتح الصورة، واسحب Kinana.app إلى Applications، ثم أخرج الصورة. افتح التطبيق من Applications في Finder. الحزمة موقّعة بـDeveloper ID وموثّقة من Apple. قد يطلب Gatekeeper تأكيد فتح تنزيل جديد. إذا أفاد بأن التطبيق تالف أو تعذّر التحقق من المطوّر، راجع التجزئة وأعد التنزيل من صفحة الإصدار.
4. اختر مسار المخزن أو استخدم الافتراضي ~/KinanaVault، وراجع نتائج اكتشاف المهارات قبل الاستيراد.
5. لتثبيت الموجّه، افتح معاينة الموجّه في المعالج أو الإعدادات وأكّد الوجهتين. يستخدم الموجّه أداة CLI المضمّنة في التطبيق.
